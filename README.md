# Project Lucido

시도하고 싶은 마음에 물꼬를 틉니다.

Project Lucido 한 장짜리 소개 페이지(PC용, 모바일 대응)입니다.

- 파일: `index.html` 한 개 (CSS 포함)
- 글꼴: Google Fonts (Jua, Noto Sans KR)
- 연락: 인스타그램 https://www.instagram.com/odenhobler / 이메일 odenhobler@naver.com

## GitHub Pages로 공개하기

1. 이 저장소에 `index.html`과 `README.md`를 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
4. 1~2분 뒤 `https://<깃허브 아이디>.github.io/<저장소 이름>/` 주소로 열립니다.
